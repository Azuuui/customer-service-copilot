# 演示知识库混合检索设计

## 检索流程

用户输入依次经过文本规范化、中文分词、标准问题/用户问法/关键词精确匹配、BM25 召回、pgvector 语义召回和 RRF 融合排序，最终返回最多 4 条原始演示知识。

精确命中优先于融合候选。RRF 公式为：RRF(d) = Σ 1 / (60 + rank_i(d))。

## 数据边界

演示数据位于 data/demo-knowledge.json。检索文本包括标准问题、用户问法、关键词、分类和虚构答案，不包含创建人、修改人、时间或日志。

检索层只返回数据文件中的原始演示答案，不自动生成价格、时效、承诺或真实业务结论。发布检查使用 data/golden-query-set.json 中的虚构查询。

向量模型为 BAAI/bge-m3，维度 1024，使用 cosine distance 和 HNSW vector_cosine_ops 索引。模型不可用时不得生成假向量。
