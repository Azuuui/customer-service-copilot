# 客服辅助演示项目系统架构

## 核心组件

- React 网页端：提供查询工作台和管理界面。
- Spring Boot API：负责会话、RBAC、知识治理、公告、排班、状态和审计。
- Python 检索服务：负责文本规范化、BM25、向量检索和 RRF 融合。
- PostgreSQL/pgvector：保存演示业务数据、知识投影和向量索引。
- 可选身份提供方：正式部署时通过后端交换一次性授权码；前端不保存 Client Secret。

## 安全边界

- 默认认证模式为 disabled，模拟登录必须显式开启。
- 运行数据库模式时必须显式提供密码和管理员标识。
- 会话令牌只以 SHA-256 摘要持久化，账号停用后会话立即失效。
- 菜单隐藏不作为授权依据，受保护接口由服务端逐请求检查角色。
- 身份提供方配置只从后端环境变量读取，不进入前端或版本库。

## 当前范围

这是使用虚构数据的技术演示，不连接真实客服、工单、税务、支付或员工系统。部署者需要自行补充正式身份校验、网络边界、密钥管理、监控和备份策略。
