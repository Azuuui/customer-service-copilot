# 客服辅助演示项目数据库设计

## 设计边界

PostgreSQL 16 保存演示账号、权限、审计、知识治理、查询反馈、公告、排班和状态数据。pgvector 保存 BAAI/bge-m3 生成的 1024 维向量。数据库不保存明文密码、授权码、访问令牌或身份提供方密钥。

本仓库只包含虚构演示数据。knowledge_items 是 Python 检索服务读取的投影，Spring Boot 负责业务版本与治理写操作。

## 迁移与安全

迁移文件位于 db/migrations，按文件名顺序执行，并在 schema_migrations 中登记。已经登记的迁移不得修改或重复执行。

- 会话只保存随机令牌的 SHA-256 摘要和过期状态。
- 首次登录只授予普通客服角色，高权限必须显式授予。
- 审计日志不得写入密钥、令牌或完整敏感参数。
- 知识版本采用不可变快照；发布新版本不覆盖历史内容。
- 查询事件使用匿名会话键哈希，不保存可逆客户端标识。

运行数据库模式前必须显式提供 DATABASE_URL。请只使用本地虚构数据，不要把生产数据库备份放入仓库。
