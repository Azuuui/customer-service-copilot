# Customer Service Copilot

一个使用虚构数据的客服辅助技术演示，包含 React 查询工作台、Spring Boot 业务 API、Python 混合检索服务和 PostgreSQL/pgvector 数据层。

## 公开数据声明

仓库中的知识、问法、答案、账号和流程均为虚构演示内容，不对应真实公司、员工、客户或生产业务。请勿把真实凭据、数据库备份、客户资料或内部文档提交到本仓库。

## 主要能力

- 标准问题、用户问法和关键词精确匹配
- BM25 与向量检索的 RRF 融合
- 知识版本、分类、标签和发布治理
- 会话、RBAC、账号停用和审计
- 公告、排班、工作状态和反馈管理

## 安全默认值

- 默认认证模式为 disabled。
- 模拟登录必须显式设置 COPILOT_AUTH_MODE=mock。
- 数据库密码必须通过环境变量显式提供。
- 默认不创建管理员账号。
- 服务端环境变量承载身份提供方密钥，前端不保存密钥。

复制 .env.example 为 .env，至少设置 POSTGRES_PASSWORD。详细结构和本地运行说明见 docs 目录。
